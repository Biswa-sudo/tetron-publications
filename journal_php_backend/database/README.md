# Database

Import your existing schema first. The backend is designed against the 15 tables in that schema.

Recommended:
1. Create a database named `journal_db`.
2. Import your SQL schema.
3. Copy `.env.example` to `.env` and configure credentials.
4. Create the first admin with the seed script or manually update a user role/status.

No database migrations are required for the schema supplied with this project.
